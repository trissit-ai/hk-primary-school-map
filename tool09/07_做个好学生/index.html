做个好学生

《做个好学生》属于香港三年级上册常见课文（参考清单）。目录位置已建好， 歌曲与字幕还没生成——必须先拿到权威课文全文、再由你确认曲风，才会进 ComfyUI 生成， 而且所有歌曲一律用广东话 / 粤语演唱。

当前状态 · 待权威课文全文
这一课要走的步骤
  1. 拿到权威课文全文　助手网搜并标注来源、交叉验证后逐篇给你确认（香港教材繁体、无拼音），确认后才往下走。
  2. 确认曲风：孤勇者曲风　已按分组指定（古诗《青花瓷》/ 文言文《菊花台》/ 现代文《孤勇者》），叠加「粤语演唱」约束。
  3. ComfyUI 生成粤语歌曲　本机离线生成，显式关掉 abc_planning，max_duration 固定 300；不承诺逐字唱出。
  4. 找免费图或生成图　优先 Wikimedia Commons 实拍并逐张署名，需要时才排队生成。
  5. 自检字幕与歌曲时间对准　本机离线 Whisper 词级对齐，不上传音频；行内锚点修局部快慢，数值回归验收。
  6. 自检代码后上传上线　页头 HOME + 面包屑、页尾三要素齐全，SHA 校验通过后发链接。
为什么不先填词
歌词错一个字，整首歌（约 1–2 小时生成）就白做；公开仓库的课文与音乐版权也要说清楚。 所以先搜全文 + 交叉验证 + 逐篇确认，宁可留目录位置也不凭记忆填词。想先做哪一课，来小红书说一声。
