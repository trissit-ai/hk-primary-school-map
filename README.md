# 全港小学地图（校网／地区／口岸筛选）

一个单文件网页地图：**694 所香港小学 + 97 个港铁站**，可按校网、地区、类别、通勤圈层、口岸站数、收表状态筛选，点学校弹出详情与街景／地图外链。支持双指缩放。

打开方式：直接双击 `index.html`（需联网加载地图底图），或用任意静态服务器托管。

## 数据来源

| 内容 | 来源 | 可信度 |
| --- | --- | --- |
| 学校名册、地址、电话、官网、经纬度 | 香港教育局《学校位置及资料》CSV（截至 2026-09-30） | S 官方 |
| 校网号 | 教育局《2027 年度小一入学 · 自行分配学位阶段 · 各小一学校网小学名册》 | S 官方 |
| 地铁站名与线路 | 港铁公司开放数据 `mtr_lines_and_stations.csv` | S 官方 |
| 地铁站坐标 | OpenStreetMap（Overpass API），按站名与港铁官方站名匹配，97/98 命中 | B |
| 机构榜单排名 | 商业升学机构《全港小学教育竞争力 100 强》截图识别 | C 级，仅作初筛 |
| 插班收表状态 | 逐校官网／官方 PDF 查证（覆盖走廊 242 所） | S／A／B，查不到标「未公布」 |
| 到最近港铁站距离、圈层、口岸站数 | 由经纬度直线距离推算 | D 推算，非实测 |

底图：CARTO Positron（`light_all`），浅白底 + 淡蓝水体。渲染用 Leaflet 1.9.4。

## 筛选维度

- 关键字：校名／地址／英文名
- 校网：36 个小一学校网 +「不在 POA」+「未列名册」
- 地区：全港 18 区
- 口岸站数：从罗湖／落马洲起 ≤2／4／6／9 站（东铁线站序；两口岸到同一批站的站数相同）
- 学校类别：资助／官立／直资／私立／国际／英基／特殊学校
- 通勤圈层：步行可达 ≤900m／一程驳乘 ≤3km／需两程以上
- 插班收表状态：有公布窗口／全年收表／未公布
- 只看百强（机构榜单）

## 关于「外观图片」

气泡里没有内嵌照片——教育局名册不含图片，也没有可用的开放照片源。取而代之的是每所学校都带 **「街景」与「地图」按钮**，直接用该坐标跳转 Google 街景／地图，零成本且 694 所全部可用。
