# 香港擇校工具超市（地图 · 校區篩選 · 口岸通勤）

一個 GitHub Pages 靜態站，包含一系列跨境擇校小工具：

- **工具 01 · 全港小學地圖**（`tool01.html`）：694 所香港小學 + 97 個港鐵站，可按校網、地區、類別、通勤圈層、口岸站數、收表狀態篩選。
- **工具 02 · 校區篩選工具**（`tool02.html`）：地區／校網／一條龍／類別／通勤／口岸多維交叉篩選，按匹配度排序。
- **工具 03 · 口岸通勤時間試算**（`tool03.html`）：羅湖／落馬洲／福田等口岸到學校的推算通勤時間。

線上地址（超市總入口）：**https://trissit-ai.github.io/hk-primary-school-map/**

打開方式：訪問上面的線上地址（GitHub Pages 已託管）；若要本地預覽，雙擊 `index.html`（超市入口）或 `tool01.html`（地圖，需聯網加載地圖瓦片），或用任意靜態服務器託管。

## 底图与坐标系（重要）

| 项 | 说明 |
| --- | --- |
| 底图 | **高德地图** 矢量样式（`style=7`），浅白底 + 淡蓝水体，中文标注 |
| 最大缩放 | z=19（实测 z=20 无瓦片） |
| 渲染引擎 | Leaflet 1.9.4，**CSS 与 JS 已内联进 HTML**，无外部 JS 依赖 |
| 坐标系统 | **GCJ-02**（高德使用火星坐标） |
| 坐标转换 | 由官方 WGS-84 经标准 GCJ-02 算法转换；香港实测偏移约 **595 m**（东 511 m、南 305 m） |

> 为什么必须转换：高德对香港同样套用 GCJ-02 偏移。若把 WGS-84 坐标直接画在高德底图上，每所学校会偏约 **590 米**——对判断「步行可达／口岸几站」是致命的。转换正确性已用「瓦片水体互相关」与「校址落点」双重验证。

## 为什么换掉了原底图

原版用 CARTO Positron / OpenStreetMap 瓦片。在中国大陆网络下实测：

| 瓦片源 | 连通性 |
| --- | --- |
| `basemaps.cartocdn.com` | 超时，不可达 |
| `tile.openstreetmap.org` | 超时，不可达 |
| `wprd0x.is.autonavi.com`（高德） | 正常 |

同时，境内地图可视化有明确的合规要求，可用的地图源限定为腾讯／高德／百度／天地图。CARTO 与 OSM 均不在其中。故改用高德，兼顾可达性与合规。

## 数据来源

| 内容 | 来源 | 可信度 |
| --- | --- | --- |
| 学校名册、地址、电话、官网、经纬度 | 香港教育局《学校位置及资料》CSV（截至 2026-09-30） | S 官方 |
| 校网号 | 教育局《2027 年度小一入学 · 自行分配学位阶段 · 各小一学校网小学名册》 | S 官方 |
| 地铁站名与线路 | 港铁公司开放数据 `mtr_lines_and_stations.csv` | S 官方 |
| 地铁站坐标 | OpenStreetMap（Overpass API），按站名与港铁官方站名匹配，97/98 命中 | B |
| 机构榜单排名 | 商业升学机构《全港小学教育竞争力 100 强》截图识别 | C 级，仅作初筛 |
| 插班收表状态 | 逐校官网／官方 PDF 查证（覆盖走廊 242 所） | S／A／B，查不到标「未公布」 |
| 一條龍（接龍辦學） | 教育局《2026/27 學年「一條龍」學校名單》（data.gov.hk，2026-09-01 更新） | S 官方；名單僅含資助學校，直資／私立的接龍安排不在官方名單內 |
| 到最近港铁站距离、圈层、口岸站数 | 由经纬度直线距离推算 | D 推算，非实测 |
| 底图 | 高德地图 | — |

`data.json` 中每所学校／站点同时保留两套坐标：`lat`/`lon` 为 GCJ-02（供底图与高德链接使用），`wlat`/`wlon` 为原始 WGS-84（供二次开发）。

## 筛选维度

- 关键字：校名／地址／英文名
- 校网：36 个小一学校网 +「不在 POA」+「未列名册」
- 地区：全港 18 区
- 口岸站数：从罗湖／落马洲起 ≤2／4／6／9 站（东铁线站序；两口岸到同一批站的站数相同）
- 学校类别：资助／官立／直资／私立／国际／英基／特殊学校
- 通勤圈层：步行可达 ≤900m／一程驳乘 ≤3km／需两程以上
- 插班收表状态：有公布窗口／全年收表／未公布
- 只看竞争力百强（机构榜单，非官方）

## 「竞争力榜」是什么

界面上的「竞争力榜 第 N」不是教育局的官方排名，而是**商业升学机构《全港小学教育竞争力 100 强》**的名次：

- 来源可信度 **C 级**，排名口径不公开，**只适合当初筛线索**，不能当事实依据
- 只有榜单内的学校带这个标签，其余学校无名次（不代表差，只代表不在该榜）
- 校网号不用榜单数据——已逐校用《教育局 2027 年度各小一学校网小学名册》校正

## 关于「外观图片」

气泡里没有内嵌学校照片——教育局名册不含图片，也没有可用的开放照片源。学校气泡带两个导航按钮：

- **从罗湖导航** / **从落马洲导航** — 高德导航链接，起点为对应口岸

原版的 Google 街景外链已移除（Google 地图不在可用白名单内，且 Google 街景在中国大陆无法访问）。

## 文件

- `data.json` — 同樣的數據（含 WGS-84 與 GCJ-02 雙坐標），供二次開發取用
