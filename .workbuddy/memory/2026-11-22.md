# 2026-11-22 · 工具 06 起点／学校改成「可打字搜 + 可滚动选」

## 需求
Tris 截图指 `transit-guide.html`「先填两个地方」的两个输入框，要求把数据放进去，既能打字搜，也能往下滑动选口岸或学校。

## 交付
- `transit-guide.html`（手维护单文件，无模板/构建脚本，仅首页链接它）新增两处共用的 combobox：输入即时过滤、点右侧 ▾ 展开 700 项清单滚动选、键盘 ↑↓／Enter／Esc、点击外部关闭。
- 数据：6 个具体口岸 + 694 所学校，由 `work/tools/build_transit_guide_places.py` 从 `port_commute_data.json` / `tool04_schools.json` 生成，用 `<!-- TG_PLACES_START/END -->` 标记幂等替换。**改数据后重跑该生成器，勿手改内联数组。**
- 冒烟 `work/tools/smoke_transit_guide.js`（27 断言）；`index.html` 工具 06 卡片加一条功能说明。

## 关键决策 / 踩过的坑
- **移除 `maxlength="24"`**：最长校名 63 字符（`INTERNATIONAL COLLEGE HONG KONG HONG LOK YUEN (PRIMARY SECTION)`），不移除会被截断。
- 选中候选项后派发原生 `input` 事件，联动主脚本 IIFE 里已有的 state／预览监听器，不重复实现逻辑（主脚本 400 行未动）。
- 一次性修掉两个状态竞态：`suppressInput` 标志（避免自己派发的 input 被本组件监听器当成用户打字而重新展开）＋ `blur` 改为同步 `hide()`（去掉 140ms setTimeout，消除时序不确定）。
- 口岸别名（落马洲／福田、皇岗／新皇岗等）只作搜索键不显示；「不限／还没定」不是地点所以排除；新皇岗显示名去掉「（2026-10-12 启用）」以免太长。
- **工具 06 边界不变**：下拉只是内嵌的公开名称清单，不提供路线／站位／班次／收费；privacy 段已写明「不是根据你的输入查回来的」。
